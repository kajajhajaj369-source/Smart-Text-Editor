Concept: LIFO (Last-In, First-Out). When typing text in Notepad, editing actions are pushed onto the undoStack. Pressing Ctrl+Z pops from undoStack and pushes onto redoStack.

Concept: FIFO (First-In, First-Out). Manages up to 8 recent files. Opening a new file executes enqueue. When capacity exceeds 8, the oldest entry is dequeued.

🔁 Recursion (Linked List Line Traversal)

Traverses the LineNode linked list recursively to compute word and character counts without iterative loops: 

int countWordsRecursive(Node* node) {
    if (node == nullptr) return 0; // Base case
    return countInLine(node->text) + countWordsRecursive(node->next);
}
